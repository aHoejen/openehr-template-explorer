# Sample templates: sources and licences

The OPT files are vendored unchanged, apart from the file name, except where noted.
The archetypes inside them come from the openEHR Clinical Knowledge Manager (CKM).
CKM archetypes are published under **CC BY-SA** (most under 4.0, some older ones under 3.0).
The licence and authorship metadata embedded in each file is the authority.
