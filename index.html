openEHR Template Explorer

Look inside an Operational Template: its nodes, data types, coded values and terminology bindings.

Drop an OPT 1.4 XML file here

Export one from Archetype Designer or download a template from CKM, or pick a sample above. The file is parsed in your browser and is not uploaded anywhere.

  • Tree: COMPOSITION → SECTION → ENTRY → CLUSTER → ELEMENT, showing RM type, at-code, occurrences and archetype roots.
  • Data: each ELEMENT's data type, units and ranges, and its allowed codes (local at-codes or an external value set).
  • Bindings: SNOMED CT, LOINC and other bindings on nodes and on coded values, in a table you can export as CSV.
  • Teaching flags: unbound elements, local-only value sets, SNOMED-CT(2003)-style version stamps, and AQL paths you can copy.
